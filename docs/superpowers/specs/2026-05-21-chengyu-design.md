# Design: 课文成语 Feature

**Date:** 2026-05-21  
**Status:** Approved

---

## Overview

Add a "课文成语" feature sourced from `data/小学高级华文成语表.docx`. The DOCX contains ~160 Chinese idioms (成语) from Singapore Primary 3–6 textbooks. Each idiom has one or more grade/lesson/example-sentence entries. Users can browse by grade filter, run a dictation session (parent or student mode), or study idioms one-by-one with all example sentences displayed.

---

## 1. Data Model (`src/data/chengyu.ts`)

```typescript
export interface ChengYuExample {
  grade: 3 | 4 | 5 | 6;
  lesson: number;
  sentence: string;
}

export interface ChengYu {
  id: string;           // 'cy-0', 'cy-1', …
  text: string;         // '五颜六色'
  examples: ChengYuExample[];
}

export const chengyuList: ChengYu[] = [ /* generated */ ];

/** Convert to Word[] for use in DictationView (uses first example as sentence). */
export function chengyuToWords(list: ChengYu[]): Word[] {
  return list.map(cy => ({
    id: cy.id,
    text: cy.text,
    pinyin: undefined,
    example: cy.examples[0]?.sentence ?? '',
    wordType: 'word' as const,
    isCustom: false,
  }));
}

/** Filter idioms that appear in at least one lesson of the given grade. */
export function filterChengyuByGrade(grade: 3 | 4 | 5 | 6 | 'all'): ChengYu[] {
  if (grade === 'all') return chengyuList;
  return chengyuList.filter(cy => cy.examples.some(e => e.grade === grade));
}
```

`chengyuToWords` converts each `ChengYu` to a `Word`:
- `id`: `cy.id`
- `text`: `cy.text`
- `pinyin`: `undefined` (auto-generated by `getDisplayPinyin` at render time)
- `example`: `cy.examples[0]?.sentence ?? ''`
- `wordType`: `'word'`
- `isCustom`: `false`

`filterChengyuByGrade('all')` returns the full list. For a specific grade, returns idioms where at least one example has `example.grade === grade`.

## 2. DOCX Parser Script (`scripts/parse-chengyu.mjs`)

A one-time Node.js script (ESM). Run once to generate `src/data/chengyu.ts`; commit the output; the script itself is not bundled into the app.

**Algorithm:**

1. Use `child_process.execSync('unzip -p data/小学高级华文成语表.docx word/document.xml')` to extract the inner XML as a Buffer.
2. Decode to UTF-8 string. Strip all XML tags with `/`<[^>]+>`/g` → space. Collapse whitespace.
3. The cleaned text has the format:  
   `成语 grade（lesson） example sentence [grade（lesson） example sentence …]`
4. Use a regex to tokenize into `(idiomText, gradeNum, lessonNum, sentence)` tuples. Group tuples by `idiomText` to build `ChengYu` objects.
5. Assign sequential IDs `'cy-0'`, `'cy-1'`, … in the order they appear.
6. Write the TypeScript file to `src/data/chengyu.ts`.

**Run command:**
```bash
node scripts/parse-chengyu.mjs
```

**Edge cases the script must handle:**
- Idioms longer than 4 characters (e.g., `热锅上的蚂蚁`, `三步并作两步`, `人非圣贤，谁能无过`, `不费吹灰之力`).
- Grade parentheses that use full-width characters `（` `）` as found in the DOCX.
- Entries with no example sentence — skip those tuples (the grade/lesson appears but sentence is empty before the next idiom).
- Same idiom text appearing multiple times → group all into one `ChengYu` with multiple `examples`.
- The `6（1)` variant with ASCII close-paren — treat as `6（1）`.

## 3. Types Change (`src/types/index.ts`)

Add `'chengyuStudy'` to `ViewMode`:

```typescript
export type ViewMode =
  | 'wordlists' | 'lessonSelector' | 'lessonEdit'
  | 'wordSelector' | 'dictation' | 'study' | 'studyList'
  | 'chengyuStudy';
```

`mainTab` in `WordListView` is widened from `'dictation' | 'study'` to `'dictation' | 'study' | 'chengyu'` (local to that component, not a shared type).

---

## 4. Home Page: 成语 Tab (`src/components/WordListView.tsx`)

The `mainTab` state type changes to `'dictation' | 'study' | 'chengyu'`. The tab bar adds a third button:

```
[听写]  [学习]  [成语]
```

When `mainTab === 'chengyu'`, render `<ChengYuPanel>` (see below). No other structural changes to `WordListView`.

New props added to `WordListViewProps`:
```typescript
onStartChengyuDictation: (words: Word[], label: string) => void;
onStartChengyuStudy: (list: ChengYu[], label: string) => void;
```

These are passed through to `ChengYuPanel`.

## 5. 成语 Panel (`src/components/ChengYuPanel.tsx`)

Standalone component rendered inside the `WordListView` 成语 tab.

**State:**
- `gradeFilter: 3 | 4 | 5 | 6 | 'all'` — default `'all'`
- Derived: `filtered = filterChengyuByGrade(gradeFilter)`

**Layout:**
```
Grade filter row: [全部] [P3] [P4] [P5] [P6]

Scrollable list:
  五颜六色      2 条例句
  七嘴八舌      2 条例句
  各种各样      3 条例句
  …

Bottom (sticky):
  [全部听写 (N个)]   [全部学习]
```

- Each row shows `cy.text` and `cy.examples.length 条例句`.
- Tapping a row does nothing (rows are display-only; bulk actions via bottom buttons).
- 「全部听写」→ calls `onStartChengyuDictation(chengyuToWords(filtered), gradeLabel)`
- 「全部学习」→ calls `onStartChengyuStudy(filtered, gradeLabel)`
- `gradeLabel`: `'全部'` or `'P3'`/`'P4'`/`'P5'`/`'P6'`
- Buttons disabled when `filtered.length === 0`.

## 6. Study View (`src/components/ChengYuStudyView.tsx`)

Full-screen component. Props: `list: ChengYu[]`.

**State:**
- `index: number` — current idiom index, starts at 0

**Layout (one idiom at a time):**
```
┌──────────────────────────────┐
│   七嘴八舌                    │
│   qī zuǐ bā shé              │
│   ──────────────────          │
│   三年级 第9课                 │
│   猴子们七嘴八舌地商量怎么把    │
│   月亮捞上来。                 │
│                               │
│   五年级 第3课                 │
│   同学们抬起了头，七嘴八舌地    │
│   说了起来。                   │
└──────────────────────────────┘
      ← 上一个      下一个 →
         2 / 68
```

- Pinyin generated via `getDisplayPinyin(cy.text, undefined)`.
- All `cy.examples` listed vertically with `P${grade} 第${lesson}课` label.
- Prev/Next buttons: disable at boundaries.
- Progress indicator `index+1 / list.length` at bottom.

## 7. App.tsx Changes

**New state:**
```typescript
const [chengyuStudyList, setChengyuStudyList] = useState<ChengYu[]>([]);
const [chengyuStudyLabel, setChengyuStudyLabel] = useState('全部');
```

**New functions:**
```typescript
function startChengyuDictation(words: Word[], label: string) {
  setSessionConfig({ words, grade: `成语 · ${label}` });
  setDictationKey(k => k + 1);
  setView('dictation');
}

function startChengyuStudy(list: ChengYu[], label: string) {
  setChengyuStudyList(list);
  setChengyuStudyLabel(label);
  setView('chengyuStudy');
}
```

**`handleBack` addition:**
```typescript
if (view === 'chengyuStudy') { setView('wordlists'); return; }
```

**`headerTitle` addition:**
```typescript
view === 'chengyuStudy' ? `学习成语 · ${chengyuStudyLabel}` : …
```

**`headerBack`** includes `'chengyuStudy'`.

**`toolbarContext`**: when `view === 'chengyuStudy'`, return `{ contextWords: [], resetLabel: '重置全部进度' }`.

**New render block:**
```tsx
{view === 'chengyuStudy' && (
  <ChengYuStudyView list={chengyuStudyList} />
)}
```

**`WordListView` gets two new props:**
```tsx
<WordListView
  …existing props…
  onStartChengyuDictation={startChengyuDictation}
  onStartChengyuStudy={startChengyuStudy}
/>
```

## 9. What Does Not Change

- `DictationView` — unchanged; receives ChengYu-sourced `Word[]` via existing `SessionConfig`
- `StudyListView` / `StudyView` — not used for 成语
- Existing preset word data (`wordLists.ts`) — unchanged
- All custom word storage — unchanged
- The DOCX file itself is only needed to run the parser script; it is not imported at runtime
